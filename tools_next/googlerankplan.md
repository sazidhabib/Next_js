## ফেজ ১: টেকনিক্যাল এসইও ও ইনডেক্সিং আর্কিটেকচার

গুগলের টপ ১-৫ র‍্যাংকে আসতে হলে টেকনিক্যাল আর্কিটেকচার ১০০% ত্রুটিহীন হতে হবে।

### ১.১ মাল্টি-টিয়ার সাইটম্যাপ আর্কিটেকচার (`app/sitemap.js`)
কনভার্টার সাইটে কয়েক শত থেকে হাজার হাজার URL তৈরি হয়। গুগলকে একবারে সব পেজ দিলে ক্রল বাজাটে সমস্যা হতে পারে।
* **Tier 1 (High Priority 1.0 - 0.9):** হোমপেজ `/` এবং টপ ৫০ হাই-ভলিউম কনভার্সন (যেমন `pdf-to-word`, `mp4-to-mp3`, `jpg-to-png`, `webp-to-jpg`, `m4a-to-mp3`)।
* **Tier 2 (Priority 0.8):** ফরম্যাট হাব পেজগুলো (যেমন `/pdf-converter`, `/mp4-converter`, `/png-converter`)।
* **Tier 3 (Priority 0.6):** অন্যান্য সকল ভ্যালিড কনভার্সন পেয়ার (`/[from]-to-[to]`)।
* **Last Modified & Change Frequency:** নিয়মিত আপডেট ডেট যাতে গুগল বট প্রতি সপ্তাহে নতুন করে ক্রল করে।

### ১.২ ক্রল বাজেট ও `robots.js` অপটিমাইজেশন
* **Allow:** সকল পাবলিক কনভার্সন পেজ (`/[slug]`), ব্লগ, ডকস, প্রাইসিং, সিকিউরিটি।
* **Disallow (গুগল বটের সময় নষ্ট না করতে):**
  - `/dashboard/*`
  - `/api/*`
  - `/login`, `/register`, `/checkout`
  - সেশন ও টেম্পোরারি ডাউনলোডের ইউআরএল
* **Sitemap Directive:** সঠিক লাইভ ডোমেনের সাইটম্যাপ লিংক ডিফাইন করা।

### ১.৩ Canonical Tag ও Clean Slug Structure
* স্ল্যাগ ফরম্যাট: `/[from]-to-[to]` (যেমন: `/png-to-jpg`) এবং `/[format]-converter` (যেমন: `/pdf-converter`)।
* ট্র্যাকিং কোয়েরি প্যারামিটার (`?ref=`, `?page=`) যাতে ডুপ্লিকেট কন্টেন্ট ইস্যু তৈরি না করে, তার জন্য প্রতিটি পেজে স্বয়ংক্রিয় self-referencing canonical URL থাকতে হবে:
  ```js
  alternates: {
    canonical: `https://fileconvert.com/${slug}`,
  }
  ```

### ১.৪ Bing & Yandex IndexNow ইন্টিগ্রেশন
* নতুন কনভার্সন পেয়ার বা পেজ তৈরি হওয়ার সাথে সাথে Search Engine API-তে অটোমেটিক পিং পাঠানো, যেন ২৪ ঘণ্টার মধ্যে ইনডেক্স হয়।

## ফেজ ২: প্রোগ্রামাটিক অন-পেজ এসইও ও হাই-সিটিআর মেটাডাটা

গুগলে ১-৫ নম্বরে র‍্যাংক করার জন্য **CTR (Click-Through Rate)** এবং **Search Intent Match** সবচেয়ে গুরুত্বপূর্ণ। মানুষ যখন সার্চ করে, তারা খোঁজে: **ফ্রি, কোনো সফটওয়্যার লাগবে না, কোয়ালিটি লস হবে না, দ্রুত কনভার্ট হবে**।

### ২.১ ফন্ট/কনভার্টার পেজের ফর্মুলা মেটা টাইটেল ও ডেসক্রিপশন

#### কনভার্সন পেয়ার পেজের জন্য (`/[from]-to-[to]`):
* **Title Format (৫০-৬০ ক্যারেক্টার):**
  `Convert [FROM] to [TO] Online (Free & Fast) | FileConvert`
  * *উদাহরণ:* `Convert WEBP to PNG Online (Free & High Quality) | FileConvert`
  * *অল্টারনেটিভ হাই-সিটিআর:* `[FROM] to [TO] Converter - 100% Free & No Sign-up`
* **Meta Description (১৪০-১৫৫ ক্যারেক্টার):**
  `Convert your [FROM] files to [TO] online in seconds. 100% free, secure, and preserves maximum quality. No software download or registration required.`

#### ফরম্যাট হাব পেজের জন্য (`/[format]-converter`):
* **Title:** `Free [Format] Converter Online - Convert [Format] to Any Format`
* **Description:** `Online [Format] converter. Batch convert [Format] files to PDF, JPG, MP3 and 50+ formats instantly. Secure cloud processing with automatic file deletion.`

### ২.২ অপটিমাইজড হেডিং ও কিওয়ার্ড হায়ারার্কি
* **H1 (১টি মাত্র):** `Convert [FROM] to [TO]`
* **H2s:**
  1. `How to convert [FROM] to [TO] in 3 easy steps`
  2. `[FROM] vs [TO]: Key differences & format overview`
  3. `Frequently Asked Questions about [FROM] to [TO] conversion`
  4. `Other popular [FROM] conversions`
* **H3s:**
  - প্রতিটি FAQ প্রশ্নের উত্তর
  - টেকনিক্যাল স্পেসিফিকেশন ও সিকিউরিটি গ্যারান্টি

## ফেজ ৩: হাই-ইমপ্যাক্ট স্কিমা ও রিচ স্নsnippet (Schema.org / JSON-LD)

গুগল সার্চ পেজে সাধারণ লিংকের চেয়ে স্টার রেটিং, FAQ ড্রপডাউন এবং স্টেপ-বাই-স্টেপ স্নsnippet থাকলে ক্লিকের সংখ্যা ৩-৫ গুণ বেড়ে যায়।

### ৩.১ `WebApplication` Schema
```json
{
  "@context": "https://schema.org",
  "@type": "WebApplication",
  "name": "FileConvert - Online File Converter",
  "applicationCategory": "UtilitiesApplication",
  "operatingSystem": "All (Web Browser)",
  "browserRequirements": "Requires JavaScript. Requires HTML5.",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "USD"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.9",
    "reviewCount": "1280",
    "bestRating": "5"
  }
}
```

### ৩.২ `HowTo` Schema (গুগল Rich Result-এর জন্য সেরা)
```json
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "How to convert WEBP to PNG online",
  "description": "Step-by-step guide to converting WEBP images to PNG format securely using FileConvert.",
  "step": [
    {
      "@type": "HowToStep",
      "name": "Upload your file",
      "text": "Drag and drop or select your WEBP file from your device, Google Drive, or Dropbox.",
      "url": "https://fileconvert.com/webp-to-png#step1"
    },
    {
      "@type": "HowToStep",
      "name": "Select PNG as target format",
      "text": "Choose PNG from the output format dropdown and adjust quality settings if desired.",
      "url": "https://fileconvert.com/webp-to-png#step2"
    },
    {
      "@type": "HowToStep",
      "name": "Convert and download",
      "text": "Click Convert, wait a few seconds for cloud processing, and download your converted PNG file.",
      "url": "https://fileconvert.com/webp-to-png#step3"
    }
  ]
}
```

### ৩.৩ `FAQPage` Schema (গুগলে সার্চ রেজাল্ট বড় দেখানোর জন্য)
গুগল পিপল অলসো আস্ক (PAA) সেকশনে আপনার পেজের উত্তরগুলো ফিচার করার জন্য প্রতিটি পেজে FAQPage স্কিমা বসাতে হবে।

### ৩.৪ `BreadcrumbList` Schema
`Home > Image Converter > WEBP to PNG`—গুগলের সার্চ রেজাল্টে সাইট লিংকের সুন্দর ক্রাম্ব দেখাবে।

## ফেজ ৪: হেল্পফুল কন্টেন্ট ও থিন কন্টেন্ট রোধ (Helpful Content System)

> **⚠️ গুগল স্প্যাম আপডেট ওয়ার্নিং:** গুগল এমন পেজকে পেনাল্টি দেয় যা কেবল একটি উইজেট এবং ২ লাইনের ডেসক্রিপশন রাখে ("Thin Programmatic Pages")। শীর্ষ ১-৫ এ আসতে হলে প্রতিটি পেয়ার পেজে প্রোগ্রামাটিকভাবে ভ্যালু-অ্যাডেড কন্টেন্ট থাকতে হবে:

### ৪.১ কম্প্যারিসন ম্যাট্রিক্স টেবিল (Format Comparison Matrix)
প্রতিটি কনভার্সন পেয়ার পেজে সোর্স ও টার্গেট ফরম্যাটের একটি ডায়নামিক তুলনা টেবিল থাকবে:
* ফাইল এক্সটেনশন ও ডেভেলপার / স্ট্যান্ডার্ড
* কম্প্রেশন টাইপ (Lossy vs Lossless)
* ট্রান্সপারেন্সি সাপোর্ট (Alpha Channel)
* অ্যানিমেশন ও কালার প্রোফাইল সাপোর্ট
* বেস্ট ইউস কেস (কখন কোন ফরম্যাট ব্যবহার করবেন)

### ৪.২ টেকনিক্যাল স্পেসিফিকেশন কার্ড
* MIME Type (যেমন: `image/webp` বনাম `image/png`)
* ম্যাক্সিমাম রেজোলিউশন ও ব্রাউজার সাপোর্ট

### ৪.৩ মানুষের বাস্তব প্রশ্ন ও উত্তর (PAA FAQ Section)

## ফেজ ৫: কোর ওয়েব ভাইটালস ও সার্চ ইউএক্স (Core Web Vitals & Speed)

গুগল টুলস জাতীয় পেজের জন্য স্পিড এবং ইউজার এক্সপেরিয়েন্সকে র‍্যাংকিংয়ের টপ ফ্যাক্টর হিসেবে গণ্য করে।

1. **Largest Contentful Paint (LCP) < ১.৫ সেকেন্ড:**
   - কনভার্টার উইজেট যেন পেজ লোড হওয়ার সাথে সাথে দৃশ্যমান হয় (Above-the-fold)।
   - ভারী কোনো স্ক্রিপ্ট বা থার্ড-পার্টি ট্র্যাকার হেডে ব্লকিং রাখা যাবে না।
2. **Cumulative Layout Shift (CLS) = ০:**
   - ফাইল আপলোড জোন, ব্যানার বা বাটনে কোনো লেআউট শিফট হওয়া যাবে না। উইজেটের ফিক্সড হাইট / কন্টেইনার থাকবে।
3. **Interaction to Next Paint (INP) < ১০০ মিলি-সেকেন্ড:**
   - ফাইল ড্র্যাগ-অ্যান্ড-ড্রপ করার সাথে সাথে ইন্সট্যান্ট ইউজার ফিডব্যাক (প্রগ্রেস বার বা ড্রপ স্টেট)।
4. **জিরো-ফ্রাস্ট্রেশন সার্চ ইউজার এক্সপেরিয়েন্স (No Pogo-Sticking):**
   - ইউজার যেন পেজে এসে ১ ক্লিকেই কনভার্সন শুরু করতে পারে। অতিরিক্ত বিভ্রান্তিকর বিজ্ঞাপন বা ফাঁকা ক্লিক রাখলে বাউন্স রেট বাড়বে এবং গুগল র‍্যাংক কমিয়ে দেবে।
